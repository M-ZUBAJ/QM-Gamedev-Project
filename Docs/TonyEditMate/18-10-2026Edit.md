# Tony's edits, 18/10/2026: day / time / coin counters, full HUD builder, night spawning

Asked for by Marko: a coin counter and a day counter on the HUD, and an exact time when night begins so enemies
can start spawning.

## What was planned (and done)

### 1. DaylightCycle (Tony's script, `Assets/Script/World/DaylightCycle.cs`)
- **Day number**, starting at **Day 1**. It goes up at **sunrise** (when Dawn starts), so "DAY 8 - Night" is
  the night after day 8.
- **Exact parts of the day**, set in the Inspector (Time Of Day: 0 = midnight, 0.5 = noon):

  | Part | Starts at | Clock |
  |---|---|---|
  | Night | **0.77** | 18:28 |
  | Dawn | **0.23** (= night ends) | 05:31 |
  | Morning | 0.30 | 07:12 |
  | Noon | 0.45 | 10:48 |
  | Afternoon | 0.55 | 13:12 |
  | Dusk | 0.70 | 16:48 |

- **Clock time** (e.g. `14:30`) and **real seconds until night / until morning**.
- **Events** for other scripts (static, subscribe from anywhere, any time):
  `DaylightCycle.NightStarted(int day)`, `DaylightCycle.DayStarted(int day)`, `DaylightCycle.PhaseChanged(DayPhase)`.
- `DaylightCycle.Current` reaches the one in the scene: `.Day`, `.Phase`, `.IsNight`, `.ClockText`,
  `.SecondsUntilNight`, `.SecondsUntilMorning`.

### 2. HUD counters (Tony's scripts, `Assets/Script/UI/HUD/`), top-right of the screen
- **DayCounter**: `DAY 5 - Noon`, `DAY 8 - Night`.
- **TimeCounter**: `14:30 - Night in 2:15`, and at night `22:10 - Morning in 3:40` (countdown in real minutes).
- **CoinCounter**: reads Marko's `PlayerCoins.Instance.Coins` and redraws on `CoinsChanged`.
  A **Look** dropdown picks how the coin is shown:
  - **Auto Icon**: a gold coin drawn by the script (no art needed). *(Assumption: there is no coin object to
    photograph, since enemies give coins directly.)*
  - **Static Icon**: a 2D picture (PNG imported as Sprite).
  - **Animated Icon**: an `.aseprite` animation.
  - **Text Name**: a word instead of a picture, e.g. `Coins: 12`.
  - **Text Color** is adjustable in every look.
  - `PlayerCoins.cs` itself is **not changed**.

### 3. Tool: **Tools > UI > Build HUD** (`Assets/Script/Editor/HUDBuilder.cs`)
Builds the **whole** HUDCanvas from scratch, so it can be brought back if it's deleted:
Crosshair, Health / Hunger / Stamina bars (same sprites, sizes, positions and colors as the hand-made one)
and the top-right Day / Time / Coin counters. Saves `Assets/Prefabs/UI/HUD/HUDCanvas.prefab` and puts it in the
open scene. Asks before replacing an existing prefab or scene copy. Guide: `Docs/HUD Setup.md`.

### 4. Marko's `EnemySpawner` (`Assets/Combat/Scripts/EnemySpawner.cs`)
Enemies spawn when night starts and are removed when day starts, using the new DaylightCycle events.
Every change is marked `// [Tony] ...` and keeps Marko's original code in a comment, so it can be put back.
New settings in his Inspector: **Spawn At Night** (on) and **Enemies Per Night** (3).

**To undo it:** delete the lines marked `// [Tony]` in `EnemySpawner.cs` (nothing of Marko's was removed).
If I decided to remove I will tell you in the what app chat.
